# 🎵 Music Website

A modern and responsive music-themed web interface built using HTML and CSS, featuring a visually appealing UI, navigation system, styled content sections, and a background-based immersive design.

---

##  Features

-  Modern and clean UI design  
-  Full-screen background image with overlay effect  
-  Responsive navigation bar  
-  Smooth hover animations  
-  Glassmorphism-style sections  
-  Lightweight static website (HTML + CSS only)
